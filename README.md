# React Search Location App

A tech test clone of the pick-up location search box on [Rentalcars.com](https://www.rentalcars.com)

### How to Run

To clone the repository and run the app locally follow these steps:

```shell script
$ git clone https://github.com/cloverc/search-location-app.git
$ cd search-location-app
$ npm install
$ npm run start
```

Open http://localhost:1234 to view it in the browser.
